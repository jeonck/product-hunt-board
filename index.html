2026-11-22

에이전트 "실행 환경" 데이 — 터미널 코딩 에이전트의 모델 라우팅, 데스크톱 멀티 에이전트 팀, 에이전트마다 격리 머신. 11/19~21 에이전트 검증·거버넌스·안전망 흐름이 실행 인프라 쪽으로 이어짐. 로컬·온디바이스 AI 흐름도 계속(Resurf·Zapyso — 어제 Glassmail과 같은 결).

Rankhog #1
Reddit에서 내 제품을 찾는 사람을 자동 포착해 서브레딧 규칙에 맞는 도움되는 답글을 쓰고 본인 계정에서 사람 속도로 게시하는 고객 확보 오토파일럿.
Pain: 인디·소규모 제품에 Reddit은 최고의 고객 채널인데, 관련 글을 일일이 찾고 서브레딧마다 규칙·말투에 맞는 답글을 쓰는 데 시간이 다 감. 스팸처럼 보이면 밴 당함.
해결: Radar가 구매자 서브레딧을 감시해 신선한 글 포착 → 규칙·스타일을 읽고 답글 초안 → 모더 수준 검수 → 본인 승인 또는 오토파일럿 게시. 계정이 없으면 웜업으로 키워 소유권 유지. MCP로 Claude·ChatGPT·Cursor에서 실행. $99/월, 7일 무료.
Resurf #3
Mac 네이티브 개인 컨텍스트 라이브러리 — 북마크·노트·PDF·이미지를 모아 로컬 시맨틱 검색으로 찾고, MCP로 Claude·Cursor·Codex에 컨텍스트를 넘김.
Pain: 레퍼런스·글·아이디어가 브라우저 북마크·스크린샷·폴더·노트에 흩어져 필요할 때 못 찾음. AI가 빨라질수록 개인 컨텍스트가 더 귀해지는데 도구마다 기억이 따로 놈.
해결: 로컬 시맨틱 검색 + Similar Vibe로 "기억나는 대로" 찾기, Smart Spaces로 저장할수록 자동 갱신되는 컬렉션, Ollama 포함 자기 AI 프로바이더로 커스텀 AI 액션(제목·태그 추출). Electron에서 네이티브 Swift로 재구축, iCloud 동기화는 선택.
oovi #7
데스크톱 위 나만의 AI 팀 — 리더 봇이 계획하고 연구원·작가·비평가가 분업, 외부로 나가는 액션은 승인받고 실행.
Pain: 1인 회사는 연구·작성·마케팅·검토를 혼자 다 해야 하는데, 채팅박스 하나로는 팀이 안 됨. 에이전트가 멋대로 메일을 보내거나 게시할까 봐 맡기기도 꺼려짐.
해결: 역할별 봇 분업 + 각 봇 화면을 열어 작업 지켜보기 + 외부 발송·게시·클릭 전 정확한 액션을 보여주고 승인 대기. BYOK면 무료(Claude·GPT·Gemini·Grok·로컬 모델), 내장 모델 $10/월부터 크레딧 소멸 없음, 로컬 우선, 텔레그램 연동.
Omi CLI #8
터미널 코딩 에이전트 — 레포를 읽고 계획을 세워 diff를 하나씩 승인받고 테스트 통과까지 반복, 턴마다 13개 모델 중 맞는 것을 자동 선택.
Pain: 코딩 에이전트가 모델 하나에 묶이면 쉬운 수정도 비싼 모델로 돌리거나 어려운 문제를 약한 모델에 맡김. 수정 후 테스트가 깨지면 손으로 되돌려야 하고 git 없는 변경은 복구가 어려움.
해결: 난이도별 모델 자동 라우팅(DeepSeek·Gemini·Gemma·gpt-oss·GLM 등 13개) → diff 승인(yes/no/always) → 테스트 통과까지 반복 → /undo로 git 없이도 마지막 작업 전체 복원. USD 단일 플랜(5시간·주간 한도 명시) + 무료 플랜. npm i -g @builditomi/cli.
Ulika #12
Claude·Cursor·Codex로 만든 사이트용 비주얼 에디터 — GitHub+Vercel 연결 후 누구나 페이지에서 문구·이미지를 고쳐 Publish.
Pain: AI로 주말에 React·Vite·Next 사이트를 뚝딱 만드는데, 마케팅이 헤드라인 하나 바꾸려 하면 티켓이 됨 — 레포를 열 수 있는 사람만 건드릴 수 있어 "완성"된 사이트가 사실상 손대기 어려움.
해결: 프로젝트 연결하면 Ulika가 감지 → 팀 누구나 페이지에서 직접 문구·이미지 편집 → Publish. CMS 이관 없음, 엔지니어에게 오타 수정 요청 없음. 오픈 베타 무료.
Zapyso #19
Mac 온디바이스 회의 노트·받아쓰기 — 봇이 회의에 안 들어오고, 음성인식·요약 모두 기기 안에서 처리, 무료.
Pain: 회의 노트 봇은 통화를 남의 서버로 보내야 하고 봇이 회의에 들어오는 것 자체가 부담. 받아쓰기도 클라우드행이라 민감한 내용을 맡기기 꺼려짐.
해결: Zoom·Teams·Meet·Slack 통화 시작 시 Mac에서 마이크+통화 오디오 직접 녹음 → 1분 뒤 결정사항·다음 단계·열린 질문 요약(발언 시점 링크) → 우측 ⌘ 키로 어느 앱에나 받아쓰기. 음성인식 NVIDIA Parakeet, 요약 Google Gemma 온디바이스, 오프라인 동작, 계정 없음. Apple Silicon + macOS 15 필요, 모델 4~6GB 최초 다운로드.
Render Sandboxes
에이전트마다 격리된 Linux 컴퓨터 — Firecracker microVM이 1초 이내 시작, 유휴 시 서스펜드돼 과금 중단, 도메인 단위 아웃바운드 통제.
Pain: 에이전트가 코드를 실행·테스트하려면 격리된 머신이 필요한데, 컨테이너 공유는 위험하고 VM 띄우는 건 느리고 비쌈. 유휴 시간에도 과금이 계속됨.
해결: 유저·작업마다 microVM, Claude Code·Codex 등 어떤 하네스든 실행, Docker Compose로 앱 전체를 띄워 에이전트 변경을 직접 테스트. 유휴 시 서스펜드(파일·메모리 유지, 컴퓨트 과금 중단), 도메인 허용목록, 크레덴셜 브로커링(얼리 액세스 — 키가 샌드박스 안에 안 들어감), 수천 개 동시 실행, 실제 사용 CPU/메모리만큼 과금. 공개 베타. 11/4 출시 당시 #4, 오늘 보드 재노출(11/21 업데이트).

접목 제안

  1. Omi CLI식 "난이도별 모델 자동 라우팅 + diff 승인 + 테스트 통과까지 반복 + git 없는 /undo"를 sdlc-runner 에이전트 실행 루프에 — 쉬운 작업은 저렴한 모델, 어려운 작업은 강한 모델로 자동 배정해 토큰 비용을 줄이고, 모든 변경은 diff 승인 게이트를 통과, 실패하면 세션 단위 되돌리기. 어제 UndoGuard 롤백 안전망과 한 쌍을 이룸.
  2. Render Sandboxes식 "에이전트마다 격리 microVM + 유휴 서스펜드 + 도메인 허용목록 + 크레덴셜 브로커링"을 sdlc-runner의 실행 환경 표준으로 — 병렬 서브에이전트마다 자기 머신을 주고, 나가는 네트워크는 허용 도메인만, 크레덴셜은 주입식으로 전달(샌드박스 안에 키를 두지 않음). 홈랩 Kubespray 네임스페이스 격리의 클라우드 버전 — 로컬 격리와 같은 원칙, 외부 실행용.
  3. Resurf식 "개인 컨텍스트 라이브러리 + MCP로 에이전트에 컨텍스트 전달"을 모듈러 RAG 설계에 — 온프렘 K8s + Qdrant RAG에 "로컬 시맨틱 검색 + MCP 경유 컨텍스트 주입" 패턴을 그대로 적용: 문서를 모으는 저장소와 에이전트가 읽는 MCP 레이어를 분리하고, 사용자가 왜 저장했는지(메모·태그)까지 컨텍스트에 포함시켜 검색 품질을 올림.

에이전트 거버넌스·안전망 데이 — 출시 이후에도 에이전트가 지표를 보고 스스로 고치는 루프, 에이전트 실수 되돌리기, 경로 단위 접근 통제, 에이전트 간 공유 메모리 통제. 11/19~20 에이전트 검증·신뢰 흐름의 연장선, 오늘은 "에이전트에게 어디까지 맡기고 어떻게 되돌릴 것인가" 쪽으로 무게 이동.

Stitch Loop
Google Labs의 상시 가동 프로덕트 에이전트 — 라이브 메트릭을 보고 고칠 것을 골라 격리 클라우드 샌드박스에서 수정하고 GitHub PR로 열어 사람이 승인, 머지 후 지표가 실제로 움직였는지 계속 확인. 기본 루프 3개(보안·지연·접근성), 보안 루프는 Gemini 4 Carbon + DeepMind CodeMender.
Pain: 코딩 에이전트의 일은 PR 머지에서 끝남. 출시 후 취약점 패치·체크아웃 속도·가입 이탈 분석 같은 일은 계속 쌓이는데, 어느 변경 하나가 가장 중요한지 신호가 로그·행동·피드백 곳곳에 흩어져 있음.
해결: 목표 기반 evergreen loop 4단계(제안→해결책+트레이드오프→샌드박스 빌드+PR→지표 반영 확인). 180개 이상 통합·커스텀 MCP·CLI로 컨텍스트 연결, Antigravity 같은 다른 코딩 에이전트도 Stitch CLI/MCP로 컨텍스트 공유. 전 세계 대기자 명단, Google AI Ultra 우선.
Glassmail #4
AI가 Mac을 절대 떠나지 않는 빠른 네이티브 Mac 메일 앱 — Apple Intelligence 또는 Gemma/Qwen 소형 로컬 모델로 요약·초안·AI 검색, 오프라인에서도 동작. Claude·Claude Code·Codex·Cursor가 메일 검색·읽기는 가능하되 매번 허용/거부, 발송·삭제는 불가.
Pain: 현대 메일 앱은 월 $10–30 구독에 AI가 읽으려고 메일을 자기 서버로 보냄. 무료 앱은 2012년 수준에 멈춤. "예쁜 네이티브 앱 + 온디바이스 AI + 한 번만 결제"라는 세 번째 선택지가 없음.
해결: Glassmail 자체 메일 서버 없음 — Mac이 제공자와 직접 통신, 비밀번호는 Keychain 보관. LM Studio/Ollama 연동도 가능. 일회성 결제 $29(선착순 100명 이후 $49), 14일 무료 체험, macOS 14 이상.
Shipyard #13
Claude Code·Cursor·Codex 안에서 도메인·DNS·호스팅·DB·이메일·결제까지 자동 세팅하는 로컬 CLI + MCP 서버 — 계정 한 번 연결하면 새 제품마다 약 1시간 만에 자기 도메인에 라이브, 코딩 도구에는 실제 스택에 맞춘 빌드 프롬프트를 건넴.
Pain: AI가 코드를 몇 분 만에 짜는데, 진짜 병목은 통합 잡일 — 도메인 구매·DNS·호스팅·DB·이메일 인증·Stripe·시크릿 관리에 제품당 약 12시간. 설정이 귀찮아 시작조차 안 하는 아이디어가 쌓임.
해결: 만들 것과 비용을 미리 검토받고(지출은 승인 필요) 실행 버튼 한 번. 중단해도 만든 것은 계속 동작. shipyardmcp.com 자체가 이 방식으로 런치됨.
gitroots #21
GitHub 위의 거버넌스 레이어 — 개발자·팀·AI 에이전트마다 경로 단위 접근만 부여(나머지는 안 보임), 변경은 웹·모바일·CLI에서 승인하는 싱크 요청으로, 누가·어느 레포에서·언제 무엇을 했는지 검색 가능한 감사 이력.
Pain: 외주·파트너에게 일 맡기려면 레포 전체를 넘겨줘야 했고, AI 코딩 에이전트가 같은 문제를 더 키움. Git 제공자는 "누가 접근 가능한지"는 알지만 "각자 실제로 무엇을 할 수 있는지"는 통제 못 함.
해결: 오버레이(매핑한 경로만 담은 별도 목적지)에만 푸시, 변경은 매핑 검사 후 승인 전까지 소스에 닿지 않음. Claude Code·Codex 등 에이전트도 사람과 동일한 검사·승인 통과. Starter 무료, 유료 $19/월부터.
AI Context Flow MCP
모든 AI 도구·에이전트·팀에 동기화되는 통제 가능한 메모리 레이어 — MCP 서버 한 번 연결하면 Claude에 저장한 것을 ChatGPT·Grok·Cursor가 같은 버전으로 읽음. 프로젝트·고객별 버킷, 접근 권한, 전체 버전 이력과 롤백, Memory Studio.
Pain: AI 도구 10개면 기억도 10개로 흩어져 서로 어긋나고, 누가 무엇을 바꿨는지 기록도 없음. ChatGPT 메모리는 Claude·Gemini·Cursor에 닿지 않아 매번 다시 설명해야 함.
해결: "AI 컨텍스트는 정크 서랍이나 블랙박스가 아니라, 정리되고 내 조건으로 공유되며 항상 되돌릴 수 있어야 한다" — 버킷별 역할(기여자/뷰어), 활동 로그, 에이전트가 잘못 덮어써도 버전 복원. 5,000명 이상 사용, 7일 무료 체험.
Codemany
자기 인프라에서 GitHub Actions 실행 — 잡마다 새 VM의 fresh 러너, 고장 러너 자동 교체·자체 업데이트·정리. runs-on 한 줄만 바꾸면 됨. 메이커 주장 3배 빠름(매일 공개 벤치마크), 분당 과금 없음, 월 $20에 머신 2대.
Pain: GitHub 호스티드 러너 요금이 쌓이고 느림 — 메이커는 10월 Actions 청구 $582. 셀프호스트 러너는 직접 띄우고 유지·정리하는 손이 많이 듦.

에이전트의 디지털 트윈(도구·기록·문서·RAG)에서 합성 페르소나가 실전처럼 몰아붙이고, 실패를 자동 eval·재현하는 시뮬레이션 플랫폼.
Pain: 자율주행은 수백만 마일 시뮬레이션 후 도로에 나가는데 에이전트는 그 단계 없이 바로 유저 앞에 섬. 실패는 유저가 먼저 발견.
해결: 월드 상태 변화 기준 eval(말이 아닌 행동 평가), 프로덕션 실패를 깨진 단계부터 리플레이, 수정 후 회귀 검증.
수치(벤더 주장): 실패 -82%, 비용 -97%, $13M 시드, 11/11 GA.
Harness Memory #6
에이전트용 장기 기억, 하네스 간 공유. Claude Code·Codex·Hermes가 하나의 메모리 공유.
Pain: 세션마다 기억 초기화, 하네스마다 따로 접착해야 함.
해결: 엔진 선택(Mem0·Graphiti·Hindsight·ReMe·BYO), 턴 시작 회상·턴 중 도구 사용·턴 종료 기록(글루 코드 없음), 사용자별 격리, 삭제는 사람만(버전 기록 유지), 오픈 스펙.
three.dev #21
라이브 트래픽에서 조용한 실패를 찾아 심각도 순으로 묶고, 상위 건을 MCP로 코딩 에이전트에 넘겨 수정 제안.
Pain: 환불 기한 오답처럼 크래시도 알림도 없는 실패는 고객 불만으로만 발견됨. eval은 아는 실패만 커버.
해결: 라이브 요청 백그라운드 스코어링(무지연), 실패 모드 그룹화, 실제 대화·증거 첨부.
Oxagen #29
에이전트 미션 컨트롤. 런마다 사람·작업·변경 코드·비용·결과 연결, 팀 공용 스킬 공유, 예산·승인 규칙.
Pain: 수십 개 런, 누구도 나눌 수 없는 모델 청구서, 어느 런이 어느 줄을 바꿨는지 기록 없음.
해결: 런-사람-작업-코드-비용-결과 한 레코드, 운영자·에이전트·워크스페이스별 지출, 승인 규칙 강제.
Gnista #22
맥 노치/메뉴바에서 코딩 에이전트 28개 + 훅 추적, 승인 요청이 뜨면 노치에서 바로 허용/거부, 해당 터미널·tmux·에디터로 점프.
Pain: 승인 하나 못 봐서 에이전트가 10분 대기.
해결: 조용한 노치(대기 중인 것만 알림), SSH 지원, 일회성 구매·계정 불필요, 6개 언어.
Foxpit #31
Claude는 계획·리뷰만, 저렴한 모델이 코드 작성. 리드 에이전트가 태스크 분할, 3D 오피스 뷰, 레포 공유 메모리, 5시간 제한 후 자동 재개.
Pain: Opus가 하루에 주간 쿼터 62% 소진. 손으로 5개 터미널 오가며 컨텍스트 복사.
해결: 계획/실행 모델 분리로 비용 절감, 공유 메모리로 세션 연속성, 로컬 실행(코드는 PC 밖으로 안 나감).
Didit MCP #16
신원 확인·사기 검사를 MCP 서버로. ChatGPT·Claude·Cursor 등에서 자연어로 국가별 신분증 검사 추가, 거부 사유 조회, 사기 규칙 90일 백테스트.
Pain: 국가별 검증 플로우·사기 규칙 튜닝에 항상 개발자 필요.
해결: 컴플라이언스 담당자도 자연어로 운영, 콘솔 역할 권한만 위임.

접목 제안

  1. **sdlc-runner에 Plurai식 시뮬레이션 게이트** — 배포 전 디지털 트윈에서 adversarial 페르소나로 돌리고, three.dev식 라이브 실패 탐지를 eval set 졸업 루프(책 5장)와 연결.
  2. **Oxagen식 런 거버넌스 관측가능성 모듈** — sdlc-runner 런마다 사람·작업·변경·비용·결과를 한 레코드로, 예산·승인 규칙 포함.
  3. **Gnista + Foxpit식 비용·승인 운영** — 모델별 쿼터 관측, 승인 대기 알림, 계획(고급 모델)/실행(저렴한 모델) 분리 라우팅.
